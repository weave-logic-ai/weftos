# [45] Introducing GPT-5.4

**Citation:** OpenAI (2025). "Introducing gpt-5.4." External link (OpenAI blog post).
**URL:** https://openai.com/index/introducing-gpt-5-4/ — released March 5, 2026 per OpenAI's own release cadence; note the arXiv-style "(2025)" citation year in refs.tsv reflects the paper's citation-key convention (based on preprint-season norms), not the actual public release date.

## Summary
GPT-5.4 is OpenAI's frontier model release unifying advances in reasoning, coding, and agentic workflows, including native state-of-the-art computer-use capability (agents operating GUIs/applications directly rather than via a bolt-on browsing tool), tool search, and a 1M-token context window. Released as GPT-5.4 Thinking / GPT-5.4 Pro at launch (neither available to free-tier users); GPT-5.4 mini and GPT-5.4 nano followed about two weeks later, with mini reaching free-tier users and nano API-only.

## Role in Skill-3D
GPT-5.4 plays a dual role in the paper, both larger than any other single model in the reference set:
- **Baseline agent:** one of four closed-source MLLM agents evaluated under all four settings (w/o Tools, w/ Tools, Think3D, Skill-3D) in the main results table.
- **Teacher model:** explicitly used "as the teacher model for skill distillation and SFT data generation" (§4.1) for the open-source Qwen3-VL-4B/8B students — used only on training samples, never at evaluation time for the student models.
- **Fixed backbone for all ablations:** Table 3's module-ablation study, Fig. 4's tool-usage-distribution analysis, and the source→target skill-transfer experiment ("All settings use the same static skills and GPT-5.4") all standardize on GPT-5.4 specifically, making it the paper's de facto reference model for qualitative tool-selection analysis.

## API / Weights
- Closed weights, API-only (OpenAI API / ChatGPT / Codex).
- No open release of any GPT-5.4 variant, including mini/nano.
- Native computer-use capability is a distinguishing feature relevant to agent design generally, not spatial reasoning specifically.

## Reported Spatial Benchmark Numbers
Within Skill-3D, GPT-5.4's *behavior* rather than its absolute score is the more citable finding: Fig. 4 documents that as a non-agentic/direct-tool-use baseline, "GPT-5.4 mostly calls GroundingDINO" and "overuses GroundingDINO" for both depth/distance/size tasks and spatial-relation/direction tasks — i.e. it exhibits generic-tool bias rather than task-adapted tool selection, which Skill-3D's learned skill-routing corrects. Absolute VSI-Bench/MMSI-Bench scores specific to GPT-5.4 require Table 1's per-model rows (not fully machine-extracted in this pass); the aggregate closed-source gain (42.9→64.5 average across all four backbones, GPT-5.4 included) is confirmed from the running text.

## WeftOS Relevance
**Verdict: WATCH (as cloud teacher).** GPT-5.4 can never be an on-device WeftOS component — closed weights rule that out entirely — but as the teacher model in Skill-3D's own distillation pipeline it is architecturally important to understand if WeftOS follows the same recipe (cloud teacher → open-weight Qwen3-VL student). Its native computer-use / tool-search capability is also directly relevant prior art for any WeftOS design that wants an agent capable of driving external tools or applications, not just answering spatial questions about a captured scene.
