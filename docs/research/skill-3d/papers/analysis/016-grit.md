# Ref 16: GRIT

**Citation:** Y. Fan, X. He, D. Yang, K. Zheng, C. Kuo, Y. Zheng, S. J. Narayanaraju, X. Guan, X. E. Wang. "GRIT: Teaching MLLMs to Think with Images." arXiv:2505.15879, 2025 (NeurIPS 2025).

**Source:** arXiv:2505.15879 (https://arxiv.org/abs/2505.15879)

## Summary

GRIT trains MLLMs to produce reasoning chains that interleave natural language with explicit bounding-box coordinates pointing at regions of the input image, so the model's chain-of-thought is visually grounded without any external tool or pixel re-injection. Training uses GRPO-GR, a reinforcement-learning method that needs minimal supervision — as few as 20 image-question-answer triplets from existing datasets — to teach the interleaved text/box reasoning format.

## Method specifics

- **Tool API shape:** none — there is no external tool call. Bounding boxes are tokens generated by the model itself during decoding (detected via regex matching of integer quadruplets), not calls to a segmentation/detection module.
- **Output return path:** none — explicitly, "the model does not receive additional pixel inputs"; it continues reasoning purely from its own internal understanding of the original image, informed by the coordinates it just generated. This is a pure architectural/decoding mechanism, not an agent-tool loop.
- **Planner/executor split:** none — single model generates both bounding-box tokens and natural-language reasoning in one unified autoregressive stream; it chooses at each step whether to emit a box or continue text.
- **Error handling:** format rewards enforce correct use/order of special reasoning tokens; "rethink" token pairs let the model revise an initial output; the RL reward includes a GPT-4o-judged binary correctness score over (question, predicted answer, ground-truth) triplets — a training-time correction signal, not a runtime tool-repair loop.

## Results

Across six datasets: VSR 72.9% accuracy / 0.325 grounding IoU (Qwen backbone); TallyQA 47.8% accuracy / 0.447 grounding IoU; GQA 62.8% accuracy / 0.485 grounding IoU; OVDEval grounding IoU range 0.398-0.560. Numbers found in the paper's reported results.

## WeftOS relevance

**SKIP.** GRIT's grounding is purely internal to the model's attention over the original image — bounding-box tokens are not metric, not tool-derived, and not verifiable evidence; they are exactly the kind of appearance-based coordinate generation that WeftOS's "honest geometry" principle wants to distinguish from real tool-grounded geometry. Useful only as a negative example / cautionary contrast, not as a pattern to adopt.
