# [23] GPT-4o System Card

**Citation:** Hurst et al. (2024). A. Hurst, A. Lerer, A. P. Goucher, A. Perelman, A. Ramesh, A. Clark, A. Ostrow, A. Welihinda, A. Hayes, A. Radford, et al. "Gpt-4o system card." arXiv preprint arXiv:2410.21276.
**URL:** https://arxiv.org/abs/2410.21276

## Summary
The GPT-4o (OpenAI, 2024) system card documents an autoregressive "omni" model trained end-to-end across text, vision, and audio in a single network, accepting and producing any combination of text/audio/image inputs and text/audio/image outputs (video handled as sampled frames, not a native modality). It matches GPT-4 Turbo on text/code while being faster and ~50% cheaper via the API. Unlike a typical benchmark paper, the system card's primary focus is capability description, safety evaluation, and third-party red-teaming, not spatial-reasoning benchmarking specifically.

## Architecture / Notes
- Single end-to-end network across text, vision, and audio — no separate ASR/TTS/vision-encoder pipeline stitched together, which is what "omni" refers to.
- Trained and evaluated primarily for general multimodal capability and safety, not for embodied/3D spatial tasks — VSI-Bench-style benchmarks postdate this system card.
- Published August 2024 (arXiv submission October 2024), making it the oldest model in Skill-3D's closed-source comparison set by roughly a year or more relative to GPT-5.4/Gemini-3.

## Role in Skill-3D
**Weakest/oldest closed-source baseline agent.** GPT-4o is one of four closed-source MLLM backbones evaluated (§4.1) under all four settings — w/o Tools, w/ Tools, Think3D, and Skill-3D — and is the earliest-generation model in that lineup (2024, vs. GPT-5.4/Gemini-2.5/Gemini-3 from 2025–2026). This makes it the natural "floor" baseline in Table 1/3.3 against which the newer models and Skill-3D's own gains are contrasted.

## API / Weights
- Closed weights, API-only (OpenAI API / ChatGPT).
- No open release, no downloadable checkpoint of any kind.
- Standard commercial API terms apply; not a code/weights licensing situation at all.

## Reported Spatial Benchmark Numbers
No isolated primary-source GPT-4o VSI-Bench/MMSI-Bench/BLINK/CV-3D number was independently verified in this pass beyond the paper's own aggregate closed-source statement (avg. 42.9 → 64.5 across all four backbones, which includes GPT-4o). GPT-4o's absolute spatial-reasoning benchmark numbers were not a focus of the original system card — it predates VSI-Bench-style embodied/spatial benchmarks becoming standard evaluation practice. Any specific per-benchmark figure attributed to GPT-4o should be sourced from Skill-3D's own Table 1, not from OpenAI's original 2024 report, which does not report these benchmarks at all.

## WeftOS Relevance
**Verdict: SKIP (as a target backbone).** GPT-4o is included in Skill-3D purely as a legacy baseline for comparison; it is not the frontier choice for a new WeftOS spatial-agent design, and by the time of a WeftOS rewrite it will be two-plus generations stale relative to what's available. No action needed beyond citing it accurately as "the oldest baseline in the comparison table" if referencing Skill-3D's results — it carries no architectural or licensing lessons relevant to a Rust rewrite.
