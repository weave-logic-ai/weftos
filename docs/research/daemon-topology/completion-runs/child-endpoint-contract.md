## Child endpoint contract for the implementation lead

**Use a separate child-only UDS.** The current daemon accepts on `paths.socket()` and classifies the peer by process group; a Seatbelt child that calls `setsid` can reach that owner endpoint as `Owner`. The worktree’s `sandbox_check` addition narrows that case, but it classifies all sandboxed same-UID processes and still depends on caller classification at the owner socket. [daemon.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/daemon.rs:3353>), [child_peer.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/child_peer.rs:119>)

1. **Bind and serve:** In `daemon::run`, bind a parent-controlled `child.sock` beside the owner `kernel.sock`, with a separate accept loop. Pass every connection to the existing JSON RPC handler with a forced child/untrusted endpoint class, regardless of PID, UID or process group; unknown credentials must never become `Owner`. Reject RVF and streaming protocols there unless explicitly needed. Keep the owner socket’s existing CLI behavior. Remove the child socket on shutdown and safely reclaim its stale path on boot. [daemon.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/daemon.rs:2828>)

2. **Gate by endpoint before authorization or dispatch:** Carry an `RpcEndpoint::Child` value through `handle_connection_classed` → `dispatch_json_line` → `authorize_caller`. The child endpoint accepts only `mesh.challenge/register/heartbeat/unregister`, `project.anchor.submit`, `kernel.handshake`, `project.token.refresh`, the currently used `shared.*` methods, and the authenticated `project.nested.*` methods. Reject every other method **regardless of supplied owner token or literal `admin`**. Continue treating the client library’s implicit literal `admin` as anonymous on this endpoint; registration and anchors retain their existing nonce/signature checks, while `shared.*`, refresh and nested calls retain project-token scope and the nested handler’s master check. This avoids relying on the process-group test as the child boundary. [daemon.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/daemon.rs:3876>), [project_token_scope.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/project_token_scope.rs:38>), [project_lifecycle_rpc.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/project_lifecycle_rpc.rs:132>)

3. **Point every child parent call at it:** Set `SupervisorConfig`’s parent socket to `child.sock` before `Launcher::write_run_files`. `SpawnFile.parent_socket` then feeds bootstrap registration, heartbeat/unregister, anchor transport and `ParentLink` without a second client path change. Keep `project_boot_link::verify_parent_socket`; `ParentLink` sends a bearer project token without a prior signed challenge, so socket ownership and a parent-controlled path matter. [boot.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/project_supervisor/boot.rs:359>), [project_boot.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/project_boot.rs:330>), [parent_link.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/parent_link.rs:398>)

4. **Constrain access:** Seatbelt should allow `network-outbound` and socket metadata reads for the **literal child socket only**, plus bind/inbound for its own kernel socket. Do not grant the owner `kernel.sock` or its containing directory; test symlink and alternate-path attempts. Put the child socket in a parent-controlled directory outside the child’s writable run directory. For Linux containers, mount that directory read-only at a stable guest path, mount a separate guest runtime writable, and mount bootstrap/pin/policy/revocation material read-only. A directory mount, rather than a bind mount of the socket inode, lets a surviving container reconnect when the daemon replaces the socket after restart. Arrange UID mapping so `verify_parent_socket` succeeds before sending a token. [sandbox.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/project_supervisor/sandbox.rs:97>), [spawn.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-types/src/project/spawn.rs:39>)

**Required tests:** An escaped (`setsid`/`setpgid`) Seatbelt descendant sending literal `admin` to the child endpoint must fail `auth.token.issue`, `project.revoke` and `kernel.shutdown`; a stolen owner token on that endpoint must fail them too. Registration, signed anchor submission, project-token shared calls and master-scoped nested calls must still work. Prove the owner CLI retains its normal socket access, and prove the sandbox cannot connect to owner `kernel.sock` through a symlink or alternate path. The existing peer tests exercise a child *classified by process group*, so they do not prove the escaped case. [daemon_peer_tests.rs](</Users/mathewbeane/.codex/worktrees/topology-finish/weftos/crates/clawft-weave/src/daemon_peer_tests.rs:32>)

**ADR scope:** D10 requires a distinct inner WeftOS instance with isolated runtime, chain and identity, a master-controlled governance cap and explicit outer-mesh registration. The worktree’s `project.nested.*` routes cover nested **project kernels**, not that instance contract. D9 permits pluggable sandbox drivers; a minimal Linux container implementation can select one supported engine and fail closed for unavailable drivers. Supporting every listed engine is not a prerequisite for fixing the child endpoint.
